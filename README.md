# PackPal

A mobile travel companion built with React Native and Expo.

## Features

- Personal trip planning
- Smart packing lists
- Collaborative packing with shared trips
- Travel itinerary management
- Location-based landmark discovery
- Weather information
- Light and dark themes

## Tech Stack

- React Native & Expo
- JavaScript
- Firebase Authentication & Firestore
- React Navigation
- React Native Maps

## Getting Started

```bash
npm install
npx expo start
```

Firebase configuration and required environment variables must be set up before running the application.
